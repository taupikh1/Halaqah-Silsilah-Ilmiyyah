PUSTAKA HALAQAH SILSILAH ILMIYYAH

Baca offline
Ekstrak ZIP web ke satu folder. Buka index.html di browser. Pilih Terbaru
untuk mengikuti arsip sumber dari halaman 1 sampai 477, atau Terlama untuk
memulai dari ujung arsip. Pencarian judul, transkrip, dan filter seri berjalan
secara lokal. Tombol lanjut di halaman materi mengikuti nomor dalam serinya.

Fitur membaca
Pencarian di Daftar materi mencakup seluruh koleksi. Di halaman materi,
Cari di halaman ini menyorot kata pada teks. Gunakan tombol panah untuk
berpindah antarhasil. Tandai materi favorit atau selesai dari halaman
materi. Pintasan Lanjutkan baca membuka materi dan posisi terakhir.
Status ini disimpan di browser yang sama.

Audio
Ekstrak ZIP Audio-Halaqah yang sudah tersedia ke folder yang sama. Gabungkan
isi folder audio/ di samping index.html. File MP3 lama tetap cocok dengan versi
web ini. Saat online, tombol Putar audio mencoba audio lokal atau file Pages
terlebih dahulu, lalu tautan audio publik artikel tersebut. Jika keduanya
gagal, tautan ke artikel sumber tersedia pada pemutar.

Audio latar dan tema
Sakelar Putar di latar belakang ada di setiap halaman materi. Saat dimatikan,
audio dijeda ketika browser menyembunyikan tab. Saat dinyalakan, browser
dapat tetap memutar audio selama perangkat mengizinkan. Pilihan sakelar
dan tema terang atau gelap disimpan di browser.

Ekspor audio
Klik Ekspor file audio di halaman materi atau pada rekaman di menu Audio
offline. File masuk ke alur unduhan browser. Cek Unduhan atau aplikasi Files
pada HP. Ekspor dari Audio offline bisa dilakukan tanpa internet. Ekspor
langsung dari server audio eksternal bergantung pada izin sumber.

Simpan offline di GitHub Pages
Saat audio berhasil dimuat, pilih Simpan offline untuk menyimpan rekaman di
browser setelah mengonfirmasi Simpan. Buka Audio offline dari halaman awal
untuk melihat ukuran dan menghapus satu atau semua rekaman.
Untuk sumber eksternal, penyimpanan bergantung pada izin server
sumber. Bukalah web minimal sekali saat online agar browser menyimpan
halaman untuk dibuka kembali tanpa jaringan.

Pasang pembaruan di repo yang sudah ada
Ekstrak ZIP Pembaruan. Ganti index.html dan tambahkan sw.js ke direktori
yang sama di repo. Folder images/ dan audio/ yang sudah terpasang bisa
dipakai kembali. Untuk pemasangan baru, gunakan isi ZIP Web di root branch
yang dipakai oleh GitHub Pages. Sertakan .nojekyll.

Menambahkan audio ke repo
Untuk materi yang memiliki file MP3, folder audio/ dari paket asli bisa
digunakan. Untuk menambahkan audio secara manual, simpan ke audio/ID.mp3,
misalnya audio/13262.mp3. ID tiap materi ada di Katalog.csv. Paket audio
lengkap lebih besar dari batas ukuran situs GitHub Pages.

Sumber
https://ilmiyyah.com/archives/category/halaqah-silsilah-ilmiyah

Pembaruan materi otomatis
Workflow Sinkron Materi Ilmiyyah berjalan pada menit ke-01 setiap jam.
Repo yang memakai workflow ini perlu Settings → Pages → GitHub Actions.
Untuk uji pertama atau sinkron segera, buka Actions → Sinkron Materi
Ilmiyyah → Run workflow. Pilih branch utama.

Cek materi terbaru di halaman awal membuka revisi terakhir di GitHub Pages.
Kalau workflow masih berjalan, materi baru muncul setelah deploy berhasil.
Saat offline, versi terakhir yang sudah tersimpan masih bisa dibuka.

Tema
Pilih Terang, Gelap, atau AMOLED di header. AMOLED memakai dasar hitam
pekat. Tema dan data bacaan tersimpan di browser yang sama.

Pasang v5 di repo yang sudah tayang
Ganti index.html, sw.js, updates.json, Katalog.csv dan BACA-DULU.txt di root.
Pastikan scripts/sync.py, .github/workflows/sinkron-halaqah.yml dan file
.nojekyll ikut masuk ke branch utama. Folder images dan audio dari repo
yang sudah ada tetap dibutuhkan.

Kalau pengelola file HP menyembunyikan folder .github, gunakan GitHub
Add file → Create new file. Masukkan .github/workflows/sinkron-halaqah.yml
sebagai nama file dan salin isi YAML dari paket. Untuk .nojekyll, buat file
tersebut di root. File ini boleh diberi satu baris kosong.
Setelah workflow ada di branch utama, pilih Pages → Source → GitHub Actions,
lalu jalankan Sinkron Materi Ilmiyyah secara manual untuk deploy pertama.
